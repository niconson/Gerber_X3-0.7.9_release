# Gerber_X3-0.7.9_release
Просмотрщик и редактор Гербер-файлов, программа сделана для Схематор&Платформ https://github.com/niconson/FreePCB-2

Требуемая для сборки библиотека qt 5.12.10

Сборка в VS 2022, но необходимо использовать  плптатформу Visual Studio 2017 (v141) с++ ,
расширение qt vs tool версии 2.10 (ДЛЯ wimdows 7) или 3.4.1 (для windows 10 и выше) 

Поддерживаемые  ОС Windows 7 и выше.
